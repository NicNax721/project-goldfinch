# 🐦 Project-Goldfinch

> This software is made and distributed only to specific LGUs.

A DTR-System custom made for specific Local Government Units in the Philippines following CSC form generation standards.

# 🌟 Highlights

- Faster than the Device's Proprietary Biometric Data Parser in a record time (<5s).
- Employee Information Database Management. Handles:
    - ID number and Work Department assigned
    - Work Modes
    - Firstname, Middlename, Lastname, Suffix, DOB
    - Daily Time Record
- Solves the Flexi-Time problem for 24-hr work schedule employees.
- Denoising for Multiple and Mistaken Time Inputted.
- Open Time Record and Data Time Record for both double checking.
- CSC Form 48 Daily Time Record generation and Printing.
- Auto-archiving for previous year DTRs
- Employee Department Statistics including Government LGU wide HR statistics.

# ℹ️ Overview

This software is made using C++ and Qt UI, and Sqlite as the Database. I made this software to address a City LGU HR's problem; existing procedure too slow parsing times for each employee dtr and printing report every 1st/2nd quincena and for whole month. I was an OJT there for a month and I found the work tidious.
